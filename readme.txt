mGBA celio edition（128MB ROM・16MB セーブ対応版）
==================================================

これは何か
----------
GBA エミュレーター mGBA の改造版「mGBA celio edition 2.0.0」に、
128MB（128MiB）までの ROM と、16MB までのセーブを扱えるようにする変更を加えたものです。

リリース: rom128-5

  - ちょうど 64MB の ROM を読み込むと、ROM の後ろ半分（32MB）が
    0x0A000000〜0x0BFFFFFF に見えます。
    0x08000000〜0x09FFFFFF と 0x0C000000〜0x0DFFFFFF は、これまでどおり前半の 32MB です。
  - 128MB の ROM は、32MB のバンク 4 つとして扱います。0x08000000〜0x09FFFFFF は常にバンク 0（前半）で、
    0x0A000000〜0x0BFFFFFF の窓にバンク 1〜3 のどれかが見えます（ゲームが 0x0B7FFF00 への書き込みで選びます）。
    起動とリセットのときはバンク 1 です。64MB 以下の ROM は、これまでどおりに動きます。
  - 32MB 以下の ROM は、これまでの mGBA と同じように動きます。
  - celio edition の通信機能（Celio-mGBA-Link のスクリプト）は、2.0.0 と同じように使えます。

rom128-5 の変更（mGBA のリリース 5 つ目）
-----------------------------------------
  - 画面サイズを ×2 以上にして ROM を開くと、設定は ×2 以上なのに画面が ×1 になる不具合を直しました。
    あわせて、画面サイズが保存されず、起動のたびに ×1 に戻る不具合も直りました。
  - それ以外（ROM・セーブ・ネット通信・録画など）は rom128-4 と同じです。

rom128-4 の変更（mGBA のリリース 4 つ目）
-----------------------------------------
  - 同梱の DLL のうち Brotli（libbrotlidec.dll・libbrotlicommon.dll）を 1.2.1 に更新しました。
    1.2.0 には、細工された圧縮データで問題が起きる不具合（CVE-2026-111497）があり、1.2.1 で直っています。
    mGBA 自身は Brotli を直接使いませんが、同梱の libfreetype-6.dll が読み込むため、安全のため入れ替えました。
  - 画面の録画ができるようになりました（FFmpeg 入り）。メニューの「オーディオ/ビデオ → ビデオ録画...」
    （または「Record GIF/WebP/APNG...」）から、webm（VP9+Opus）・mp4（H.264+AAC）・GIF などで保存できます。
  - FFmpeg が入ったぶん、フォルダ（zip）が大きくなりました。FFmpeg は GPL のライセンスなので、
    下の「録画機能（FFmpeg）と GPL」に GPL の表示とソースの入手先を書きました。
  - ゲームの動作・128MB の ROM・16MB のセーブ・ネット通信・セーブの自動バックアップなどは rom128-3 と同じです
    （mGBA のソースも rom128-3 と同じです）。

rom128-3 の変更（mGBA のリリース 3 つ目）
-----------------------------------------
  - liru 氏の変更を取り込みました（rom128-2 と同じソース）。
      * 画像の解像度の拡張と、可逆圧縮の画像（HGZ1）への対応
      * HGZ1 の地図の素材データ（パレット・メタタイル参照・属性）と、昼夜のパレット（A9 v2・0〜16 段階）への対応
      * 128MB ROM の 32MB の窓ごとに、画像のキャッシュを分けました
      * ウィンドウの名前を「mgba-clio ver: rom128-N」（N はリリースの番号）にそろえ、実行ファイルの名前を mgba-celio.exe にしました
  - 音が出ない件を直しました。rom128-2 の zip は、音を切った設定ファイル（config.ini に mute=1・volume=0）を
    入れて配っていたため、初めて開いたときに音が出ませんでした。この版は設定ファイルを入れていません。
    初めて開いたときから音が出ます（ミュートしたいときは、メニューの「ツール → 設定 → 音声/映像」か、
    config.ini の [ports.qt] に mute=1）。
  - 技術仕様は hgx4-abi.md・obj256-abi.md を見てください。

使い方
------
  1. このフォルダを、英数字だけのパスの場所に置いてください
     （例: C:\mGBA-rom128）。日本語の入ったパスだと通信機能がうまく動かないことがあります。
  2. mgba-celio.exe を起動し、ROM を開きます。
  3. フォルダの中の DLL やフォルダ（platforms など）は消さないでください。起動に必要です。

ROM・ゲームのデータは入っていません。

設定の保存先
------------
  ボタン・ショートカットなどの設定は、mgba-celio.exe と同じフォルダの config.ini・qt.ini に保存します
  （フォルダの portable.ini があるとき。消さないでください）。
  ふつうの mGBA とは設定が混ざりません。
  - 書き込めない場所（Program Files など）に置くと、設定が保存されません。
  - 新しい版に入れ替えるときは、前のフォルダの config.ini と qt.ini を新しいフォルダに写すと設定を引き継げます。
  - 同じフォルダの mgba-celio.exe を 2 つ同時に開くと、あとから閉じたほうの設定が残ります。
    設定を変えるときは 1 つだけ開いてください。

ネット通信（通信対戦・交換）
----------------------------
  メニューの「ファイル → ネット通信...」から使えます。スクリプトやブラウザは要りません。
  1. どちらか 1 人が「へやを つくる」を押し、出た 4 けたの番号を相手に伝える
  2. 相手は番号を入れて「へやに はいる」を押す
  3. 2 人とも、ゲームのポケモンセンター 2 階の受付で通信をはじめる
  - 2 人とも同じ ROM を使ってください。
  - Celio（https://github.com/Celio-Link）の公開の中継サーバーを使います。
    通信の中身（ポケモンのデータなど）はサーバーを通ります。ROM は送られません。
  - 「サーバー」の欄で、つなぐ中継サーバーを変えられます（空のまま＝公開の Celio のサーバー）。
    手元で動かした Celio-Server を使うときは「ホスト名:ポート」を入れ、「wss（暗号あり）」を外します。
    「既定に もどす」で公開のサーバーに戻ります。入れたものは次に開いたときも残ります。
  - Windows 版だけの機能です。Celio-mGBA-Link の Lua スクリプトと同時には使わないでください。
  - 中継サーバーが 2026-10-03 以降の新しい形式（パケットの配列）で通信データを受け取る版に対応しました。2026-10-03 より前の古い中継サーバーに繋ぐときは、環境変数 MGBA_CELIO_NET_LEGACY=1 を付けて起動してください。

実機の GBA と通信する（USB の変換器）
------------------------------------
  GBA の通信ケーブルを USB の変換器（GBLink / Celio の RP2040 の変換器）につなぎ、
  PC に さしてから「ファイル → ネット通信...」を開きます。ブラウザのページは要りません。
  - 「この mGBA と 実機を つなぐ」… この mGBA のゲームと実機で通信します（ネットは使いません）。
    実機とこの mGBA の両方で、ポケモンセンター 2 階の受付から通信をはじめてください。
  - 「ネットの へやに 実機で はいる」にチェックしてから「へやを つくる」「へやに はいる」…
    この mGBA ではなく実機が部屋に入ります（相手はこの mGBA・ブラウザの Celio・実機のどれでも）。
  - 変換器は COM ポート（USB シリアル）として見えるものを使います。一覧に出ないときは
    「さがしなおす」を押してください。変換器のファームウェアが古いと COM ポートが無いことがあります
    （そのときは https://launcher.gblink.io で更新）。
  - 実機には 32MB の ROM（カートリッジ）を使います。64MB・128MB の ROM の後ろの部分は実機では読めません。

処理落ちを減らす（CPU を 2 倍の速さに）
----------------------------------------
  ゲームの計算だけを速くします（画面・音・時計・通信の速さはそのまま）。
  何も設定しなければ 2 倍です。処理が重い場面でカクつきにくくなります。
  - 本物の速さに戻すときは、mGBA の設定ファイル（config.ini）の [ports.qt] に
    overclock=1 と書いてください（2・4・8 も選べます）。
  - 環境変数 MGBA_OVERCLOCK でも選べます（設定ファイルのほうが先）。

セーブ 16MB・追加の RAM 16MB（対応したゲームだけ）
------------------------------------------------
  - セーブ（フラッシュ）を 16MB まで使えます。6MB の .sav は 6MB のまま開き、読むだけでは広げません。
    ゲームが 6MB より後ろ（バンク 96 以上）に書いたときだけ、.sav が 16MB に広がります（中身はそのまま）。
    前の版（1MB・6MB）の .sav も、中身を残したまま使えます。
    ほかのゲームの .sav は 128KB のままです。
  - 0x01000000〜0x01FFFFFF に 16MB の RAM があります（ステート保存にも入ります）。
  - どちらも、対応したゲームがこの mGBA で動いているときだけ使います。

セーブの自動バックアップ
------------------------
  - ゲームがセーブを書き終えるたびに、ROM と同じフォルダの backups\<ROM の名前>\ に
    日時の名前（例: 20261009-170734.sav）で写しを残します。
  - 5 分に 1 つまで（5 分以内に書き直されたら、そのファイルを最新の中身に置き換え）。
    新しいものから 30 個まで残し、古いものから消します。中身が同じときは作りません。
    ただし 8MB 以上のセーブ（16MB に広がったもの）は、1 つが大きいので 10 個までです。
  - 「ファイル → Save games → セーブのバックアップを開く」でフォルダを開けます。
  - 戻すときは、mGBA を閉じてから、使いたい写しを ROM の横の .sav と置き換えてください（名前は ROM と同じに）。
  - 切るときは config.ini の [ports.qt] に saveBackup=0 と書いてください。

ログ
----
  - mgba-celio.exe と同じフォルダの logs\mGBA.log に、時刻つきでログを書きます（置き場を変えるには環境変数 MGBA_LOG_DIR）。
  - ふだんは重大なもの（FATAL・ERROR・WARN）だけです。1MB を超えたファイルは、次の起動で mGBA.log.1 に移します（1 世代）。
  - デバッグ用に全部出すには、次のどれか 1 つ:
      起動引数 --log-debug / 環境変数 MGBA_DEBUG_LOG=1 / config.ini の [ports.qt] に debugLog=1
    全レベル（INFO・DEBUG・STUB・GAME_ERROR・ゲームの debug レジスタ・AGBPrint）を書き、16MB を超えると次の起動で mGBA.log.1 に移します。

128MB の ROM・16MB のセーブを使うゲームを遊ぶ人へ
--------------------------------------------------
  - 128MB の ROM と 16MB のセーブを使うゲームは、この版（またはそれより新しい版）の mGBA でしか遊べません。
    古い mGBA（64MB 版・celio 2.0.0 の素の版など）で開くと、タイトルで止まるか、画面が真っ黒になります
    （新しい版のゲームは、タイトルでお知らせを出します）。壊れたわけではありません。
    この mGBA に入れ替えて、もう一度開いてください。
  - 前の版（6MB のセーブ）で遊んでいた人は、セーブの変換が要ります。
      * 変換しないで開くと、ぼうけんのしょ 2 の所に「へんかんが ひつよう」と出て、選べません
        （ぼうけんのしょ 1 はそのまま遊べます）。
      * 変換は、ゲームの配布ページ（パッチを当てるページ）の「セーブの変換」で、前の .sav を選んで行います。
        元の .sav は書き換えません。できあがりは「<元の名前>_16MB.sav」になります。
        それを ROM と同じ名前の .sav にして置き、この mGBA で開いてください。
      * 変換の前に、前の .sav の写しを取っておいてください（この mGBA の backups フォルダーにも自動の写しがあります）。
  - ほかの人の mGBA にこのゲームの ROM を渡しても、新しい mGBA でないと動きません。

注意
----
  - 128MB の ROM の後ろの部分・16MB のセーブ・追加の RAM を使うゲームは、この mGBA でしか正しく動きません。
    ほかのエミュレーターや実機では使えません。
  - 動作の保証はありません。セーブデータは各自でバックアップしてください。

録画機能（FFmpeg）と GPL
------------------------
この版には、録画のために FFmpeg 8.0.1 と、その動画・音声の部品（DLL）が入っています。
同梱の FFmpeg は GPL の設定（--enable-gpl --enable-version3）で作られた MSYS2 の配布物で、
x264（H.264）・x265（H.265）・Xvid・vid.stab などの GPL のライブラリを含みます。
そのため、これらの部品は GNU General Public License（GPL）の条件に従います。
  - GPL の全文: https://www.gnu.org/licenses/gpl-3.0.html （FFmpeg の使用許諾: https://ffmpeg.org/legal.html ）
  - 同梱の FFmpeg 関連の DLL（avcodec-62.dll・avformat-62.dll・avutil-60.dll・avfilter-11.dll・swscale-9.dll・
    swresample-6.dll・libx264-165.dll・libx265-215.dll・xvidcore.dll・libvidstab.dll など）は、
    MSYS2（https://www.msys2.org/）の mingw64 のパッケージを、組み直さずにそのまま入れてあります。
  - これらのソースコードは、次の場所で入手できます。
      MSYS2 のソースパッケージの置き場（版ごとの tar と PKGBUILD）:
        https://repo.msys2.org/mingw/sources/
        https://github.com/msys2/MINGW-packages （mingw-w64-ffmpeg・mingw-w64-x264・mingw-w64-x265・mingw-w64-xvidcore など）
      本家: FFmpeg  https://ffmpeg.org/download.html （ffmpeg-8.0.1）
            x264    https://www.videolan.org/developers/x264.html
            x265    https://bitbucket.org/multicoreware/x265_git
            Xvid    https://www.xvid.com/
      版の対応は source/BUNDLED_DLLS.txt にあります。上の場所で見つからないときは、
      https://github.com/pm-start/mGBA_celio_edition の Issues で依頼してください。
  - 録画を使わないときも、これらの DLL は消さないでください（mgba-celio.exe の起動に必要です）。
  - 動画の形式によっては、国や地域によって特許などの制限がある場合があります。自己責任でお使いください。
