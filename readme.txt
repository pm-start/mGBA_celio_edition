mGBA celio edition（64MB ROM 対応版）
==================================================

これは何か
----------
GBA エミュレーター mGBA の改造版「mGBA celio edition 2.0.0」に、
64MB（64MiB）の ROM を読めるようにする変更を加えたものです。

  - ちょうど 64MB の ROM を読み込むと、ROM の後ろ半分（32MB）が
    0x0A000000〜0x0BFFFFFF に見えます。
    0x08000000〜0x09FFFFFF と 0x0C000000〜0x0DFFFFFF は、これまでどおり前半の 32MB です。
  - 32MB 以下の ROM は、これまでの mGBA と同じように動きます。
  - celio edition の通信機能（Celio-mGBA-Link のスクリプト）は、2.0.0 と同じように使えます。

使い方
------
  1. このフォルダを、英数字だけのパスの場所に置いてください
     （例: C:\mGBA-rom64）。日本語の入ったパスだと通信機能がうまく動かないことがあります。
  2. mGBA.exe を起動し、ROM を開きます。
  3. フォルダの中の DLL やフォルダ（platforms など）は消さないでください。起動に必要です。

ROM・ゲームのデータは入っていません。

ネット通信（通信対戦・交換）
----------------------------
  メニューの「ファイル → ネット通信...」から使えます。スクリプトやブラウザは要りません。
  1. どちらか 1 人が「へやを つくる」を押し、出た 4 けたの番号を相手に伝える
  2. 相手は番号を入れて「へやに はいる」を押す
  3. 2 人とも、ゲームのポケモンセンター 2 階の受付で通信をはじめる
  - 2 人とも同じ ROM を使ってください。
  - Celio（https://github.com/Celio-Link）の公開の中継サーバーを使います。
    通信の中身（ポケモンのデータなど）はサーバーを通ります。ROM は送られません。
  - Windows 版だけの機能です。Celio-mGBA-Link の Lua スクリプトと同時には使わないでください。
  - 中継サーバーが 2026-10-03 以降の新しい形式（パケットの配列）で通信データを受け取る版に対応しました。2026-10-03 より前の古い中継サーバーに繋ぐときは、環境変数 MGBA_CELIO_NET_LEGACY=1 を付けて起動してください。

実機の GBA と通信する（USB の変換器）
------------------------------------
  GBA の通信ケーブルを USB の変換器（GBLink / Celio の RP2040 の変換器）につなぎ、
  PC に さしてから「ファイル → ネット通信...」を開きます。ブラウザのページは要りません。
  - 「この mGBA と 実機を つなぐ」… この mGBA のゲームと実機で通信します（ネットは使いません）。
    実機とこの mGBA の両方で、ポケモンセンター 2 階の受付から通信をはじめてください。
  - 「ネットの へやに 実機で はいる」にチェックしてから「へやを つくる」「へやに はいる」…
    この mGBA ではなく実機が部屋に入ります（相手はこの mGBA・ブラウザの Celio・実機のどれでも）。
  - 変換器は COM ポート（USB シリアル）として見えるものを使います。一覧に出ないときは
    「さがしなおす」を押してください。変換器のファームウェアが古いと COM ポートが無いことがあります
    （そのときは https://launcher.gblink.io で更新）。
  - 実機には 32MB の ROM（カートリッジ）を使います。64MB の ROM の後ろ半分は実機では読めません。

処理落ちを減らす（CPU を 2 倍の速さに）
----------------------------------------
  ゲームの計算だけを速くします（画面・音・時計・通信の速さはそのまま）。
  何も設定しなければ 2 倍です。処理が重い場面でカクつきにくくなります。
  - 本物の速さに戻すときは、mGBA の設定ファイル（config.ini）の [ports.qt] に
    overclock=1 と書いてください（2・4・8 も選べます）。
  - 環境変数 MGBA_OVERCLOCK でも選べます（設定ファイルのほうが先）。

セーブ 1MB・追加の RAM 16MB（対応したゲームだけ）
------------------------------------------------
  - セーブ（フラッシュ）を 1MB まで使えます。ゲームが使ったときだけ .sav が 1MB になります。
    ほかのゲームの .sav は 128KB のままです。
  - 0x01000000〜0x01FFFFFF に 16MB の RAM があります（ステート保存にも入ります）。
  - どちらも、対応したゲームがこの mGBA で動いているときだけ使います。

注意
----
  - 64MB の ROM の後ろ半分・1MB のセーブ・追加の RAM を使うゲームは、この mGBA でしか正しく動きません。
    ほかのエミュレーターや実機では使えません。
  - 動作の保証はありません。セーブデータは各自でバックアップしてください。
